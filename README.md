# Echoland

A pure idle game about a busking bard, and a phone widget you can leave on a
scenic overlook. Play happens while you are gone: you come back, take the
takings, read what happened, change one thing, and leave again.

- **Overlooks** are the idle stage and the widget: procedural scenery, no UI.
- **Towns** are the exploration map paired to each overlook: shops, quests,
  shrines, taverns, minigames.
- **The story** unlocks both. The main line follows the last descendant of the
  澹人 recovering the 81 scattered leaves of their ancestral score; side lines
  hand out special overlooks, instruments and sheet music.

React 18 + Vite + TypeScript + Tailwind. No binary assets — scenery, portraits
and every sound are generated.

## Run it

```bash
cd wandering-lyre
npm install
npm run dev                 # http://localhost:5173/?skipIntro=1
                            # widget mode: /?widget=1
npm run check               # typecheck + release build + GM build + full test suite
```

## Layout

```
src/content/   authored data: every number, every line, every colour
src/game/      systems + the persisted state machine
src/render/    procedural canvas
src/ui/        screens and sheets
src/gm/        debug layer, compiled out of the release bundle
tests/         the browser suite (npm test) and the content audit (npm run audit)
```

`dist/` is generated by `npm run build` and is what gets deployed. `dist-gm/`
is the tester build — never deploy it.
